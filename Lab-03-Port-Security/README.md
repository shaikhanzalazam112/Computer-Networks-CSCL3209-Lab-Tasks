## Objective

The objective of this lab is to configure port security on a switch and understand how it controls unauthorized devices from accessing the network.

---

## Tool Used

- Cisco Packet Tracer

---

## Network Devices Used

- 1 Switch
- 4 PCs

---

## Tasks Performed

### 1. Connect PCs to the Switch

Four PCs were added to the Cisco Packet Tracer workspace and connected to the switch.

---

### 2. Assign IP Addresses

IP addresses were assigned to all four PCs to enable network communication.

---

### 3. Add Student Information

A tag containing the following information was added to the network topology:

- Name: Anzal Azam Shaikh
- Roll Number: 24108106

---

### 4. Configure Port Security

Port security was configured on the switch ports connected to the PCs.

Port security helps control which devices are allowed to connect to a switch port.

---

### 5. Test Unauthorized Device

A new PC was connected to the network to test the port security configuration.

The purpose of this test was to observe how the switch responds when an unauthorized device attempts to connect.

## Objective

The objective of this lab is to understand Virtual Local Area Networks (VLANs) and configure VLANs, access ports, and trunk ports using Cisco Packet Tracer.

---

## Tool Used

- Cisco Packet Tracer

---

## What is VLAN?

A VLAN (Virtual Local Area Network) is a logical grouping of devices on the same network. It divides a single physical network into multiple logical networks.

---

## Benefits of VLAN

- Improved Security
- Reduced Broadcast Traffic
- Better Network Management
- Flexibility
- Cost Efficiency

---

## Access Port

An access port connects end devices such as:

- PCs
- Printers

An access port carries traffic for only one VLAN.

---

## Trunk Port

A trunk port is used to connect network devices such as:

- Switches
- Routers

A trunk port carries traffic for multiple VLANs.

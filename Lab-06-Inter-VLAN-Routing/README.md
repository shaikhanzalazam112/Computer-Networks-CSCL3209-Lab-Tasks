## Objective

The objective of this lab is to configure Inter-VLAN Routing and enable communication between devices belonging to different VLANs.

---

## Tool Used

- Cisco Packet Tracer

---

## What is Inter-VLAN Routing?

Inter-VLAN Routing allows devices from different VLANs to communicate with each other through a routing device.

---

## Tasks Performed

### 1. VLAN Configuration

Created and configured VLANs on the switch.

---

### 2. Trunk Configuration

Configured the trunk interface to carry traffic between VLANs.

---

### 3. PC IP Configuration

Configured IP addresses on PCs according to their respective VLANs.

---

### 4. Inter-VLAN Routing

Configured routing to enable communication between different VLANs.

---

### 5. Connectivity Testing

Tested connectivity between devices in different VLANs using the ping command.

Successful communication confirmed that Inter-VLAN Routing was working correctly.

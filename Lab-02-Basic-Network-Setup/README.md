# Task 01 - Two PCs Connection

## Task

Create a simple network topology by connecting two PCs.

### Steps Performed

1. Added two PCs to the Cisco Packet Tracer workspace.
2. Connected both PCs using a suitable cable.
3. Checked that the connection link was active.
4. Added a tag displaying my name and roll number.
5. Verified the network topology.

---

# Task 02 - PC and Switch Connection

## Task

Create a basic network topology using one PC and one Switch.

### Steps Performed

1. Added one PC to the workspace.
2. Added one Switch to the workspace.
3. Connected the PC to the Switch using a suitable cable.
4. Checked that the connection link was active.
5. Added a tag displaying my name and roll number.
6. Verified the network topology.

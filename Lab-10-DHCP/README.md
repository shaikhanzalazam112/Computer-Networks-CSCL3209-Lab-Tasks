## Objective

The objective of this lab is to configure Dynamic Host Configuration Protocol (DHCP) on a router and automatically assign IP addresses to devices in different networks.

---

## Tool Used

- Cisco Packet Tracer

---

## Network Devices Used

- 1 Router
- 2 Switches
- PCs

---

## Tasks Performed

### 1. Network Topology

A network topology was created using one router, two switches, and multiple PCs.

---

### 2. Router Interface Configuration

The router interfaces were configured with IP addresses to connect different networks.

---

### 3. DHCP Pool Configuration

DHCP pools were configured for different networks to automatically provide IP addresses to connected PCs.

The DHCP pools were configured for:

- BSAI-4A
- BSAI-4B

---

### 4. Automatic IP Address Assignment

PCs were configured to obtain IP addresses automatically using DHCP.

---

### 5. Connectivity Testing

The network configuration was tested to verify that devices received IP addresses automatically and communicated successfully.

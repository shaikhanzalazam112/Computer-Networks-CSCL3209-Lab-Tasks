## Objective

The objective of this lab is to configure a network topology using Cisco Packet Tracer and understand basic device configuration and network communication.

## Tasks Performed

### 1. Network Topology Configuration

A network topology was created and configured using Cisco Packet Tracer.

---

### 2. PC IP Configuration

IP addresses were configured on the PCs to enable network communication.

---

### 3. Switch Configuration

The switch was configured using the Cisco IOS Command Line Interface (CLI).

Basic switch configuration was performed for network communication and management.

---

### 4. Connectivity Testing

Network connectivity and device access were tested after completing the configuration.
